# v0.4.0 — Матрица аудиторий кафедры

## Основные изменения

- В гостевом виде «Кафедра» появился отдельный режим **«Аудитории (2)»**:
  дни и пары расположены строками, аудитории кафедры — столбцами.
- Матрица доступна на неделю (6 дней, по 4 строки пар) и на один день.
- Пустые аудитории остаются в таблице, чтобы набор столбцов был постоянным при
  переключении недели. Субботняя четвёртая пара показана пустой.
- Прежние режимы «Преподаватели» и «Аудитории» сохранены.
- Новый режим работает на гостевой странице и в виджете, так как они используют
  одну страницу расписания.

## Проверка

- `npm run lint`
- `npx playwright test --grep "матрицу в госте и виджете"`

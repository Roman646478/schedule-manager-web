Все занятия аудитории в этот период переселятся в свободные аудитории и подсветятся в сетке (до обновления страницы). Отменить — кнопкой «Отменить».

Кликайте подсвеченные свободные ячейки, чтобы заблокировать их. Можно кликать несколько раз подряд.

Замены сокращений дисциплин

Применяются при загрузке расписания: сокращение слева заменяется на сокращение справа во всех файлах (группы, аудитории, преподаватели). Напр. ИЭП → ИРТС.

Файлы с неподтверждённым сдвигом

Эти файлы НЕ импортированы: дату их 1-й недели не удалось подтвердить по сетке дат. Укажите сдвиг недель для каждого файла (0 = недели файла совпадают с сеткой семестра) и импортируйте повторно.

Настройка семестра

Добавить / изменить активный семестр. Сетка недель строится от даты начала (Неделя 1 — неделя даты начала).

🗄 Архив базы

Версия — снимок всей базы целиком: занятия, справочники, семестры и журнал переносов. Переключение заменяет текущую базу выбранной версией; текущее состояние при этом само уходит в отдельную версию, поэтому переключение обратимо. Гостевая страница обновится после кнопки «Опубликовать».
Перенос между устройствами: «⬇» выгружает версию одним файлом, «⬆ Загрузить файл» принимает его на другом устройстве. Примечание и дата хранятся внутри файла и едут вместе с ним.

Полная очистка базы данных

Будут удалены все занятия, справочники и настройка семестра. Действие необратимо. Введите пароль для подтверждения.

Расписание дисциплины

Сетка недель по шаблону группы: в ячейке — вид/тема, учебные группы и аудитория. Мероприятия (Отп, ЭкзС…) в файл не идут.

Нерабочие дни

Праздники и каникулы — по одной дате на строке (формат ГГГГ-ММ-ДД). Ячейки расписания подсветятся, а при создании/переносе занятия на такой день появится предупреждение.
